## Page 2

The Empty Box
Problem

¢ Trucks drive full import containers from JNPT to
Aurangabad daily.

¢ Once unloaded, the truck drives the empty container all the
way back to the port.

¢ This creates a "Deadhead" run: burning expensive fuel with
O% return revenue.

¢ Result: Massive carbon footprint and lost earning potential
for transport fleets.



## Page 3

The Opportunity

Deadhead Earnings

Why drive empty?

Maharashtra has thousands of containers moving simultaneously. If
an importer drops a box in Pune, an exporter nearby needs one to
send back to JNPT. We connect them instantly to turn ¥O deadhead
trips into profitable return journeys.
